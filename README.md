# Atenea celular

App de estudio para el celular que funciona sin internet. Se publica con GitHub Pages.

- `index.html`, `app.js`, `sw.js`, `manifest.json`, `lib/`: la app (no contiene datos personales).
- `data.json`: cursos y tarjetas que envía la app de Atenea en Claude (**Enviar al celular**).
- `progreso/`: lo que estudias en el celular; la app de Atenea lo recoge con **Traer progreso del celular**.
